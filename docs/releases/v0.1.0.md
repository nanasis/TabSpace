# TabSpace v0.1.0

The first public TabSpace release turns Chrome's new-tab page into a local-first workspace for open tabs and persistent bookmark collections.

## Highlights

- Full Manifest V3 new-tab dashboard with current-window sidebar
- Persistent spaces and groups that survive browser tab closure
- Drag tabs from the sidebar or between groups
- Search, multi-select, bulk moves, aliases, pinning, and custom card icons
- Dense and Compact responsive card layouts
- Toby, Tabme, and TabSpace JSON import with Merge and Replace previews
- TabSpace JSON backup plus Bookmarks HTML, OneTab text, and Markdown exports
- Optional private GitHub Gist synchronization with session-only credentials
- Local runtime validation, migrations, recovery, and conflict-aware sync

## Install

1. Download `tabspace-v0.1.0.zip` from the assets below.
2. Extract the ZIP to a permanent folder.
3. Open `chrome://extensions` in Chrome.
4. Enable **Developer mode**.
5. Select **Load unpacked** and choose the extracted folder containing `manifest.json`.
6. Open a new tab. TabSpace now provides Chrome's new-tab page.

Chrome does not automatically update unpacked extensions. Download a newer release, replace the extracted files, and select **Reload** on the TabSpace extension card when upgrading.

## Verify the download

The release includes `tabspace-v0.1.0.zip.sha256`. Compare it with your downloaded ZIP using `Get-FileHash` on Windows or `sha256sum` on macOS/Linux.

## Privacy note

Tab titles, URLs, imports, and backups can contain sensitive information. TabSpace keeps organization local unless you explicitly export it or configure private Gist synchronization. Never commit exported backups or GitHub tokens.

See the [README](https://github.com/nanasis/TabSpace#readme) and [project website](https://nanasis.github.io/TabSpace/) for complete usage and security guidance.
