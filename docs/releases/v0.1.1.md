# TabSpace v0.1.1

TabSpace v0.1.1 adds automatic private-Gist discovery for cross-device restore.

## What's new

- Connecting GitHub now searches the authenticated account for private Gists containing `tabspace-backup.json`.
- The official TabSpace synchronization Gist is preferred; otherwise the newest matching Gist is selected.
- Candidate backups are fetched and validated before TabSpace links them.
- On another device, connecting the same GitHub account automatically enables **Pull** when an existing backup is found.
- Searches up to 1,000 recent account Gists in paginated requests.
- Stale local Gist metadata is cleared when the connected account has no matching backup.

## Install

1. Download `tabspace-v0.1.1.zip` from the assets below.
2. Extract the ZIP to a permanent folder.
3. Open `chrome://extensions` in Chrome.
4. Enable **Developer mode**.
5. Select **Load unpacked** and choose the extracted folder containing `manifest.json`.
6. Open a new tab to launch TabSpace.

For an existing unpacked installation, replace the files in its folder with this release and select **Reload** on the TabSpace extension card.

## Verify the download

Compare the ZIP against `tabspace-v0.1.1.zip.sha256` using `Get-FileHash` on Windows or `sha256sum` on macOS/Linux.

## Cross-device Gist restore

1. On the source device, connect GitHub and create or push the private Gist.
2. On another device, install TabSpace and connect a classic PAT for the same GitHub account with only the `gist` scope.
3. TabSpace discovers and validates the existing backup automatically.
4. Select **Pull** and confirm the restore.

Tokens stay in Chrome session storage and are never included in TabSpace backups.
