# TabSpace v0.1.2

TabSpace v0.1.2 separates live browser tabs from explicitly collected bookmarks and streamlines the GroupSpace toolbar.

## What's new

- Newly opened tabs remain in the current-window sidebar until the user explicitly collects them.
- Drag a sidebar tab onto an existing group, **New group**, or the top **Collect ungrouped** target.
- Ungrouped is hidden until it contains user-collected bookmark cards.
- Deleting a bookmark card never closes its associated browser tab and no longer moves it to Ungrouped.
- Sidebar-only live records are excluded from GroupSpace search, counts, backups, and exports.
- Collected cards remain persistent when their browser tab closes and reconnect when the same URL opens again.
- Every sidebar row now provides a close action for the live Chrome tab without changing bookmark collections.
- Duplicate active-space displays were consolidated into one toolbar with spaces on the left and search, collection/group, and space controls on the right.

## Install

1. Download `tabspace-v0.1.2.zip` from the assets below.
2. Extract the ZIP to a permanent folder.
3. Open `chrome://extensions` in Chrome.
4. Enable **Developer mode**.
5. Select **Load unpacked** and choose the extracted folder containing `manifest.json`.
6. Open a new tab to launch TabSpace.

For an existing unpacked installation, replace the files in its folder and select **Reload** on the TabSpace extension card.

## Verify the download

Compare the ZIP against `tabspace-v0.1.2.zip.sha256` using `Get-FileHash` on Windows or `sha256sum` on macOS/Linux.

## Data behavior

Existing grouped bookmarks and saved closed bookmarks remain collected. Existing open ungrouped runtime records are treated as sidebar-only until explicitly collected. Back up important tab collections before upgrading.
