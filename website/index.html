Privacy & security

Your browsing context belongs to you.

Organization stays in Chrome local storage unless you explicitly export it or enable Gist synchronization. Tokens live only in session storage and never enter backups.

Read the data-safety notes →
  • No page injectionTabSpace never runs scripts inside websites.
  • No history permissionOnly current tab metadata is requested.
  • Strict backupsRuntime IDs, tokens, and sync metadata are excluded.
  • Conflict-aware syncRemote revisions protect changed Gists.

TabSpace v0.1.1

Install the first release.

Download the verified release package and load it as an unpacked Chrome extension.

install
1  Download tabspace-v0.1.1.zip from GitHub Releases
2  Extract the ZIP to a permanent folder
3  Open chrome://extensions and enable Developer mode
4  Choose Load unpacked and select the extracted folder

The extracted folder must directly contain manifest.json. Open a new tab after installation to launch TabSpace. The release also includes a SHA-256 checksum.
